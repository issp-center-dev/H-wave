# case_soc_rashba_2d_nosub_apbc -- 2D 4x4 Rashba SOC + APBC mVMC E2E fixture

2D square Hubbard 4x4 lattice with Rashba SOC (spec §4.2.1) and APBC
in the x direction (v3.2 §3.8). `SubShape = [1, 1, 1]` (no sublattice
folding) so the folded BZ is the physical BZ. The v3.2 fixture for the
SOC + APBC branch of the bridge (`enable_spin_orbital = true`,
`BoundaryCondition = ["antiperiodic", "periodic", "periodic"]`,
orbital index in `Transfer.dat` carries spin as `2 * orb + spin`).

Parameters:

- `t = 1.0`, `U = 2.0`, Rashba `alpha_R = 0.5`.
- `CellShape = [4, 4, 1]`, `SubShape = [1, 1, 1]` -> 16 physical sites,
  32 spin-orbital labels.
- `Ncond = 8`: the APBC-in-x twist shifts the k-mesh by (pi, 0, 0) / L,
  which closes the Ncond = 6 gap that the PBC fixture uses. The next
  even filling with a well-separated HOMO-LUMO gap is Ncond = 8 (gap
  ~ 1.35). Even Ne is required by the SOC branch's pair-closure
  constraint.
- Boundary: antiperiodic in x, periodic in y and z.

## Ncond gap check

`Transfer.dat`, `OneBodyG.dat` are generated by

```bash
python scripts/emit_rashba_transfer.py --cell 4,4,1 --t 1.0 --alpha 0.5 \
    --out case_soc_rashba_2d_nosub_apbc/Transfer.dat
python scripts/emit_onebodyg_full_soc.py --cell 4,4,1 \
    --out case_soc_rashba_2d_nosub_apbc/OneBodyG.dat
```

(Both files are identical to `case_soc_rashba_2d_nosub`'s; the two
fixtures share the physical Hamiltonian and differ only in the boundary
condition.)

The pilot

```bash
PYTHONPATH=src python scripts/soc_pilot_gap.py \
    --case tests/validation/uhfk_mvmc_pairproduct/case_soc_rashba_2d_nosub_apbc \
    --ncond 4,6,8,10
```

reports (`t=1, alpha=0.5, U=2`, APBC in x):

- `Ncond=4`: gap = 6.8e-02 (OK)
- `Ncond=6`: gap = 4e-16 (REJECT; twist-degenerate at the Fermi level)
- `Ncond=8`: gap = 1.35 (OK)  <- fixture choice
- `Ncond=10`: gap = 1.10 (OK)

## Bridge and mVMC-side APBC handling

The bridge's SOC dispatch is the same as `case_soc_rashba_2d_nosub`
(v3.1 §3.8), extended so `emit_trans_def` picks up
`boundary_theta = (pi, 0, 0)` from `BoundaryCondition`. Every
boundary-crossing row in the emitted `trans.def` acquires the
wrap-phase sign flip `exp(i * pi * wraps_x) = (-1)^wraps_x`, mirroring
the sign column StdFace bakes into `orbitalidxgen.def` under
`phase0 = 180`. mVMC evaluates `<H> = -sum trans` on the periodic
site frame, so the wrap-phase-carrying `trans.def` reproduces the
physical Hamiltonian.
