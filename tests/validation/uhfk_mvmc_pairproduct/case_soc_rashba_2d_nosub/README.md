# case_soc_rashba_2d_nosub — 2D 4x4 Rashba SOC mVMC E2E fixture

2D square Hubbard 4x4 lattice with Rashba SOC (spec §4.2.1). PBC in
both directions; `SubShape = [1, 1, 1]` (no sublattice folding) so the
folded BZ is the physical BZ. The v3.1 C ケース for the SOC branch of
the bridge (`enable_spin_orbital = true`, orbital index in
`Transfer.dat` carries spin as `2 * orb + spin`).

Parameters:

- `t = 1.0`, `U = 2.0`, Rashba `α_R = 0.5`.
- `CellShape = [4, 4, 1]`, `SubShape = [1, 1, 1]` → 16 physical sites,
  32 spin-orbital labels.
- `Ncond = 6`: two lowest bands per k-point plus the Rashba-split
  branch place the 6th eigenvalue below a HOMO-LUMO gap of ~1.586
  (measured by `scripts/soc_pilot_gap.py`, plan §Task 11 Step 5).
- Boundary: PBC in all three directions.

## Ncond gap check

`Transfer.dat`, `OneBodyG.dat` are generated by

```bash
python scripts/emit_rashba_transfer.py --cell 4,4,1 --t 1.0 --alpha 0.5 \
    --out case_soc_rashba_2d_nosub/Transfer.dat
python scripts/emit_onebodyg_full_soc.py --cell 4,4,1 \
    --out case_soc_rashba_2d_nosub/OneBodyG.dat
```

The pilot

```bash
PYTHONPATH=src python scripts/soc_pilot_gap.py \
    --case tests/validation/uhfk_mvmc_pairproduct/case_soc_rashba_2d_nosub \
    --ncond 4,6,8,10
```

reports (`t=1, α=0.5, U=2`, initial Green = zeros):

- `Ncond=4`: gap = 0 (REJECT; four-fold degenerate lowest shell)
- `Ncond=6`: gap = 1.586 (OK)  ← fixture choice
- `Ncond=8`: gap = 0 (REJECT; Rashba-split branch pair-degenerate at ±k)
- `Ncond=10`: gap = 0.414 (OK)
