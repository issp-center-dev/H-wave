7.3. 線形化Eliashberg方程式¶

7.3.1. 概要¶

線形化Eliashberg方程式ソルバー（ hwave_sc）は、 RPA の枠組みで線形化ギャップ方程式の固有値問題を解くことにより、 超伝導不安定性を解析します。 超伝導転移温度 \(T_c\)は、 最大固有値が \(\lambda = 1\)に達する条件から決定されます。

アルゴリズムは以下のステップで構成されます:

  1. 裸感受率 \(\hat{X}^{(0)}(\mathbf{q})\)を計算または読み込む。

  2. 非相互作用グリーン関数 \(G(\mathbf{k}, i\omega_n)\)を構成する。

  3. RPAペアリング頂点 \(V(\mathbf{q})\)を構築する。

  4. 線形化Eliashberg方程式を解いて最大固有値を求める。

7.3.2. グリーン関数¶

k空間における非相互作用一体ハミルトニアンは、 ホッピング積分のフーリエ変換により得られます:

(7.32)¶\[\varepsilon_{\alpha\beta}(\mathbf{k}) = \sum_{\mathbf{R}} t^{\alpha\beta}_{\mathbf{R}}\, e^{i\mathbf{k}\cdot\mathbf{R}}\]

各k点でハミルトニアンを対角化し:

(7.33)¶\[\sum_\beta \varepsilon_{\alpha\beta}(\mathbf{k})\, u_{\beta m}(\mathbf{k}) = \xi_m(\mathbf{k})\, u_{\alpha m}(\mathbf{k})\]

非相互作用グリーン関数は以下のように与えられます:

(7.34)¶\[G_{\alpha\beta}(\mathbf{k}, i\omega_n) = \sum_{m} \frac{u_{\alpha m}(\mathbf{k})\, u^*_{\beta m}(\mathbf{k})} {i\omega_n - (\xi_m(\mathbf{k}) - \mu)}\]

ここで \(\omega_n = \pi(2n+1)/\beta\)はフェルミオン松原振動数、 \(\mu\)はフィリング条件から決定される化学ポテンシャル、 \(\beta = 1/T\)は逆温度です。

7.3.3. ペアリング頂点¶

簡易モード¶

CoulombIntra （ \(U\)）と CoulombInter （ \(V\)）のみが 存在する場合、ペアリング頂点はスピンチャネル（ \(W_s\)）と 電荷チャネル（ \(W_c\)）を用いて計算されます。 \(U\)と \(V\)は宣言ファイルの対称化された読み（逆向きボンドの相手 \((R, a, b) \leftrightarrow (-R, b, a)\)との平均）として入り、 パッケージ内の他の全経路と一致します。両方向を含む実数の宣言はビット単位で不変に読まれます（エルミート共役 で閉じた複素対は、不活性な虚部が実係数に折り畳まれます） （バージョン 2.0 以降、エルミート共役の相手を欠く片側宣言は読み込み時に拒否 されるため、ここに到達するのは閉じたファイルのみです。以前の簡易モード は片側ファイルを生の位相で読んでいました）:

(7.35)¶\[W_s = -U, \qquad W_c = U + 2V\]

RPA感受率は

(7.36)¶\[\hat{X}^s(\mathbf{q}) = \left[\hat{I} - \hat{X}^{(0)}(\mathbf{q})\, \hat{W}_s\right]^{-1} \hat{X}^{(0)}(\mathbf{q})\]
(7.37)¶\[\hat{X}^c(\mathbf{q}) = \left[\hat{I} + \hat{X}^{(0)}(\mathbf{q})\, \hat{W}_c\right]^{-1} \hat{X}^{(0)}(\mathbf{q})\]

一重項ペアリング頂点は

(7.38)¶\[V^S_{\alpha\beta}(\mathbf{q}) = \frac{1}{2}(W_c + W_s)_{\alpha\beta} + \frac{3}{2} (W_s\, X^s\, W_s)_{\alpha\beta} - \frac{1}{2} (W_c\, X^c\, W_c)_{\alpha\beta}\]

三重項ペアリング頂点は

(7.39)¶\[V^T_{\alpha\beta}(\mathbf{q}) = \frac{1}{2}(W_c - W_s)_{\alpha\beta} - \frac{1}{2} (W_s\, X^s\, W_s)_{\alpha\beta} - \frac{1}{2} (W_c\, X^c\, W_c)_{\alpha\beta}\]

一般モード（S/C行列定式化）¶

Hund （ \(J\)）、 Exchange （ \(J'\)）、 Ising （ \(I\)）、または PairHop （ \(P\)）相互作用が 存在する場合、ソルバーは一般化 \(S\) / \(C\)行列 定式化 [1] を使用します。

\(S\)行列と \(C\)行列は、軌道インデックス \(l_1, l_2\)の 複合インデックス空間で定義されます。 \(n_{\rm orb}\)軌道の系では、行列の次元は \(n_{\rm orb}^2 \times n_{\rm orb}^2\)です。 行列要素は以下の通りです:

注釈

クロス行の \(J\) 、 \(J'\) 、 \(I\)の各項、および \(J'\) が最終行ではなくクロス行に現れる配置は、相互作用頂点の厳密対角化による 裁定に従っています。Hund 項は \(S\) に \(-J\) ・ \(C\)に \(+J\)を、Exchange 項は両行列に \(+J'\)を、Ising 項は \(S\) に \(+I\)を与えます。SU(2) 対称な Kanamori の組（ \(J' = J\)） ではこれらが標準的な文献の行列（クロス \(S\) に \(J\)なし、 クロス \(C\) に \(-U' + 2J\)）を再現します。この修正より前に 生成された感受率ファイルは sc_vertex_versionフィールドを持たず、 相互作用に Hund・Exchange・Ising が含まれる場合は読み込み時に拒否され ます。また general スキーム（myo）のファイルでは、CoulombInter・ Hund・Ising・Exchange のいずれかに非対称なオンサイト軌道間結合 （ \(X_{ab} \neq X_{ba}\)）が宣言されている場合も、バージョン無 しファイルは拒否されます。相互作用が頂点に入る軌道の向きと、そのよう な宣言の対称化された読み方は、過去のビルドと現在とで異なっており、バ ージョン無しファイルはどのセマンティクスで生成されたかを記録していな いためです。PairHop は単純な転置ではなく エルミート共役の対に対して検査されます（2 つの宣言はその対なので向き自体 は変わっていませんが、エルミート共役で閉じていないオンサイト宣言は、そ の共役平均による読み方がバージョン刻印と同時に導入されたため、同様に 拒否されます）。PairLift は対象外です（粒子・正孔頂点への寄与が厳密に ゼロであり、向きも対称化された読み方も影響し得ません）。影響を受けない条件を規則ごとに述べると、 転置検査される 4 種の相互作用については転置対称な宣言 （ \(X_{ab} = X_{ba}\)、物理的に通常の入力すべて）、PairHop に ついてはエルミート共役で閉じた宣言（ \(P_{ba} = P_{ab}^{*}\)、 物理的に妥当な形であり、転置対称である必要はありません）です。 reduced スキームのファイルはこの向きに依存しません。

RPA感受率は

(7.40)¶\[\hat{X}^s(\mathbf{q}) = \left[\hat{I} - \hat{X}^{(0)}(\mathbf{q})\, \hat{S}\right]^{-1} \hat{X}^{(0)}(\mathbf{q})\]
(7.41)¶\[\hat{X}^c(\mathbf{q}) = \left[\hat{I} + \hat{X}^{(0)}(\mathbf{q})\, \hat{C}\right]^{-1} \hat{X}^{(0)}(\mathbf{q})\]

一重項ペアリング頂点は

(7.42)¶\[\hat{V}^S(\mathbf{q}) = \frac{3}{2}\, \hat{S}\, \hat{X}^s(\mathbf{q})\, \hat{S} - \frac{1}{2}\, \hat{C}\, \hat{X}^c(\mathbf{q})\, \hat{C} + \frac{1}{2}(\hat{S} + \hat{C})\]

三重項ペアリング頂点は

(7.43)¶\[\hat{V}^T(\mathbf{q}) = -\frac{1}{2}\, \hat{S}\, \hat{X}^s(\mathbf{q})\, \hat{S} - \frac{1}{2}\, \hat{C}\, \hat{X}^c(\mathbf{q})\, \hat{C} + \frac{1}{2}(\hat{C} - \hat{S})\]

7.3.4. 線形化Eliashberg方程式¶

線形化Eliashberg方程式は固有値問題として定式化されます:

(7.44)¶\[\lambda\, \Sigma_{\alpha\beta}(\mathbf{k}) = -\frac{T}{N_L} \sum_{\mathbf{k}', n', \alpha', \beta'} V_{\alpha\alpha';\beta\beta'}(\mathbf{k} - \mathbf{k}') \, G_{\alpha\alpha'}(\mathbf{k}', i\omega_{n'}) \, G_{\beta\beta'}(-\mathbf{k}', -i\omega_{n'}) \, \Sigma_{\alpha'\beta'}(\mathbf{k}')\]

ここで \(\Sigma_{\alpha\beta}(\mathbf{k})\)は異常自己エネルギー （ギャップ関数）であり、右辺はEliashbergカーネル \(K[\Sigma]\)を定義します。

超伝導不安定性は \(\lambda = 1\)で生じます。 SC転移には正の固有値のみが物理的に関連します。

二粒子グリーン関数¶

松原振動数の和を Nmat点の有限グリッド上で実行することで、 二粒子グリーン関数が得られます:

(7.45)¶\[G^{(2)}_{\alpha\beta;\gamma\delta}(\mathbf{q}) = \frac{T}{N_L} \sum_{\mathbf{k}, n} G_{\alpha\gamma}(\mathbf{k}, i\omega_n)\, G_{\beta\delta}(-\mathbf{k}+\mathbf{q}, -i\omega_n)\]

これにより、Eliashbergカーネルはk空間での畳み込みに帰着し、 高速フーリエ変換（FFT）を用いて効率的に計算できます。

注釈

松原 tail 補正（バージョン 2.0 以降）。 打ち切り和は厳密な二粒子グリーン 関数の主要な正の単位行列 tail を取りこぼします（ \(O(1/N_{\rm mat})\) の誤差）。被和関数の厳密な 高周波 tail は \(\delta_{\alpha\gamma}\delta_{\beta\delta}/\omega_n^2\)です （\(G\) の \(1/i\omega_n\)係数は固有基底の完全性により単位 行列で、これは FLEX のドレストグリーン関数でも同じです）。デフォルト ではソルバーがこのモデルを周波数窓内で差し引き、その厳密な全和 \(T \sum_{n \in \mathbb{Z}} 1/\omega_n^2 = \beta/4\)を解析的に 加えます。これはギャップ空間上の単位行列の正の倍数を加えることに相当 し、カーネルのスペクトルを実にする \(G^{(2)}\)の半正定値性を実用上 回復します（高次の打ち切り残差により微小な負固有値が残る場合があり、 その場合ソルバーが警告します）。補正なしでは、小さい Nmatの多軌道 計算が偽の複素固有値を報告することがあり、対称性の破れと誤読される おそれがあります。補正導入前の結果を 再現するには [eliashberg]セクションで g2_tail = falseを設定 してください。主要な \(1/\omega_n^2\)項を除去し、対称グリッド上で 奇数次逆べきが相殺するため、除外和の誤差は \(O(N_{\rm mat}^{-3})\) でスケールします（通常の整数べき高周波展開を仮定）。この補正は漸近的で、 保持される最大周波数が関連するエネルギー・自己エネルギースケールを超え ない場合は過補正になり得ます。窓端でグリーン関数が \(I/(i\omega_n)\)から要素毎の最大偏差で 0.5 を超えて外れている 場合、ソルバーは警告を出します。また、計算された \(G^{(2)}\)が有意に負の固有値を持つ場合も Nmatを指す警告を出します（これはカーネルの実スペクトル性に関する 構造的診断であり、誤差の推定ではありません）。動的（周波数分解） ソルバーはこの周波数和を取らないため影響を受けません。

FFTによるカーネル評価¶

カーネル演算 \(\Sigma_{\rm new} = K[\Sigma_{\rm old}]\)は、 ペアリング頂点 \(V(\mathbf{q})\)と \(G^{(2)}\)・ギャップ関数の積との畳み込みを含みます。 この畳み込みは以下のように効率的に計算されます:

  1. \(V(\mathbf{q})\) と \(G^{(2)}(\mathbf{q}) \cdot \Sigma(\mathbf{q})\)の逆FFTにより実空間に変換。

  2. 実空間での要素ごとの積。

  3. FFTによりk空間に戻す。

これにより計算量が \(O(N_k^2)\)から \(O(N_k \log N_k)\)に削減されます。

7.3.5. 数値解法¶

自己無撞着べき乗反復法¶

自己無撞着べき乗反復法は、最大の正の固有値を持つ固有モードに収束します:

(7.46)¶\[\Sigma^{(i+1)} = K[\Sigma^{(i)}], \qquad \lambda^{(i)} = \|\Sigma^{(i+1)}\|, \qquad \Sigma^{(i+1)} \leftarrow \Sigma^{(i+1)} / \lambda^{(i)}\]

収束を安定化するために線形混合が適用されます:

(7.47)¶\[\Sigma^{(i+1)} \leftarrow (1-\alpha)\, \Sigma^{(i+1)}_{\rm norm} + \alpha\, \Sigma^{(i)}\]

ここで \(\alpha\)は混合パラメータです。 \(\|\Sigma^{(i+1)} - \Sigma^{(i)}\| < \epsilon\) のとき収束したと判定します。

初期ギャップ関数は様々な対称性 （s波、 \(d_{x^2-y^2}\) 、 \(\cos k_x + \cos k_y\)、ランダムなど） を設定でき、特定のペアリングチャネルを狙うことができます。

Arnoldi固有値解析¶

Arnoldi法（ARPACKによる陰的再起動法）は、 Eliashbergカーネルを線形演算子として、 その主要固有値を求めます。 この方法はカーネル行列を明示的に構成することなく、 複数の固有値を同時に効率的に計算できます。

部分空間反復法¶

部分空間反復法は複数のベクトルを同時に伝播します:

  1. 全ベクトルにカーネルを適用: \(W = K \cdot V\)

  2. レイリー商を計算: \(H = V^T K V\)

  3. 小行列 \(H\)を固有値分解

  4. リッツベクトルで部分空間を更新

  5. QR分解による再直交化

この方法は縮退した固有値に対してより堅牢です。

シフト逆反復法¶

シフト逆反復変換 \((K - \sigma I)^{-1}\) を用いて、目標値 \(\sigma\)近傍の固有値を求めます。 線形方程式系はBiCGSTAB、GMRES、またはLGMRESにより 反復的に解かれます。
